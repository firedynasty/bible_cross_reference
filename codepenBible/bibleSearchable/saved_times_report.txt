SAVED TIME BUTTONS - REPURPOSABLE PATTERN
=========================================

This report covers how to repurpose the dynamic button generation pattern
from the YouTube Viewer's saved time buttons feature.


1. CONTAINER SETUP (HTML)
-------------------------

<div id="myButtons" style="display: flex; justify-content: center; gap: 8px; flex-wrap: wrap;">
    <!-- Buttons generated here -->
</div>


2. BUTTON STYLING (CSS)
-----------------------

3. GENERATE BUTTONS FROM DATA (JavaScript)
------------------------------------------

// Define color palette (buttons cycle through these)
const colors = [
    'linear-gradient(45deg, #4CAF50, #45a049)',  // Green
    'linear-gradient(45deg, #2196F3, #1976D2)',  // Blue
    'linear-gradient(45deg, #9C27B0, #7B1FA2)',  // Purple
    'linear-gradient(45deg, #FF9800, #F57C00)',  // Orange
    'linear-gradient(45deg, #607D8B, #455A64)',  // Gray
    'linear-gradient(45deg, #E91E63, #C2185B)',  // Pink
    'linear-gradient(45deg, #00BCD4, #0097A7)',  // Cyan
    'linear-gradient(45deg, #8BC34A, #689F38)',  // Light Green
    'linear-gradient(45deg, #FF5722, #E64A19)'   // Deep Orange
];

// Render buttons from an array of items
function renderButtons(items) {
    const container = document.getElementById('myButtons');
    container.innerHTML = '';  // Clear existing buttons

    items.forEach((item, index) => {
        const button = document.createElement('button');
        button.className = 'my-btn';
        button.dataset.value = item.value;     // Store data in data-* attribute
        button.textContent = item.label;       // Display text on button
        button.style.background = colors[index % colors.length];  // Cycle colors
        container.appendChild(button);
    });

    attachListeners();  // Add click handlers after creating buttons
}


4. ATTACH CLICK HANDLERS (JavaScript)
-------------------------------------

function attachListeners() {
    document.querySelectorAll('.my-btn').forEach(btn => {
        btn.addEventListener('click', function() {
            // Get stored value from data attribute
            const value = this.dataset.value;

            // Remove active class from all buttons
            document.querySelectorAll('.my-btn').forEach(b =>
                b.classList.remove('active'));

            // Add active class to clicked button
            this.classList.add('active');

            // Visual feedback animation
            this.style.transform = 'scale(1.15)';
            this.style.boxShadow = '0 5px 20px rgba(255,255,255,0.6)';

            // Do something with the value
            handleClick(value);

            // Reset button appearance after animation
            setTimeout(() => {
                this.style.transform = '';
                this.style.boxShadow = '';
            }, 400);
        });
    });
}

// Your custom handler function
function handleClick(value) {
    console.log('Button clicked with value:', value);
    // Add your logic here
}


5. USAGE EXAMPLE
----------------

// Example: Create buttons for navigation chapters
const chapters = [
    { value: '0:00', label: 'Intro' },
    { value: '2:30', label: 'Setup' },
    { value: '5:15', label: 'Main Content' },
    { value: '10:00', label: 'Summary' }

renderButtons(chapters);

// Example: Create buttons for categories

    { value: 'news', label: 'News' }
];

renderButtons(categories);


6. KEY DESIGN PATTERNS
----------------------

- Data-Attribute Storage: Use data-* attributes to store values separate from display text
- Color Cycling: Use modulo (index % colors.length) to cycle through color palette
- Re-attach Listeners: Call attachListeners() after any DOM changes to buttons
- Visual Feedback: Scale/shadow animations on click provide user feedback
- Active State: Track selected button with .active class


7. OPTIONAL: PERSISTENCE WITH localStorage
------------------------------------------

// Save buttons to localStorage
function saveButtons(items) {
    localStorage.setItem('myButtons', JSON.stringify(items));
}

// Load buttons from localStorage
function loadButtons() {
    const saved = localStorage.getItem('myButtons');
    if (saved) {
        const items = JSON.parse(saved);
        renderButtons(items);
    }
}

// Call on page load
document.addEventListener('DOMContentLoaded', loadButtons);
