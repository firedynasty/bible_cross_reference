  Location: src/BibleApp.js lines 1196-1284

  'o' Key (Page Up):
  - Scrolls UP by 90% of the KJV pane height
  - Uses kjvContentRef.current.clientHeight * 0.9 for page size
  - Prevents scrolling past the top with Math.max(0, kjvNewPosition)
  - Synchronizes both panes using percentage-based scrolling

  'p' Key (Page Down):
  - Scrolls DOWN by 90% of the KJV pane height
  - Same page size calculation as 'o'
  - Prevents scrolling past bottom with bounds checking
