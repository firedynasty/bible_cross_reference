How It Works

1. Button Click

User clicks the "Study Prompts ▼" button to toggle the dropdown menu

2. Dropdown Display

Shows 8 predefined Bible study prompt templates

3. Template Processing

Replaces {book} and {chapter} placeholders with current context

4. Clipboard Copy

Copies the processed prompt to clipboard using navigator.clipboard.writeText()
