# Bible Cross Reference

A React-based Bible reading application that displays multiple translations with the King James Version always in the right pane.

## Features

- Multiple translations: KJV, BBE, CUV (Chinese), RVR (Spanish), APEE (French), Korean, and Hebrew (with/without Strong's references)
- Side-by-side reading with KJV always displayed in the right panel
- Cross-references with easy navigation between related verses
- Reading history to track previously visited passages
- Persistent reading position saved to browser storage
- Responsive design for both desktop and mobile viewing
- Support for GitHub Pages and Vercel deployment

## Functions

- Book navigation with sidebar
- Chapter selection via dropdown
- Verse-by-verse reading with cross-reference indicators
- Cross-reference popups showing related verses
- Translation selection to change the left panel
- Reading history to revisit previous passages
- Previous/Next chapter navigation
- Return to primary reading when viewing cross-references

## Installation & Setup

```bash
# Install dependencies
npm install

# Start development server
npm start

# Run backend server (for API access)
npm run server

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
