How to Create a Scroll Button for Different Bible Translations

This guide explains how to add a button that cycles through different Bible translations and automatically applies them to a specific pane.

## Overview
The scroll button allows users to quickly cycle through available Bible translations without manually selecting from a dropdown. It automatically applies each translation to pane 2 and handles potential errors gracefully.

## Key Components

### 1. Translation Array
The translations are stored in an array with this structure:
```javascript
const translations = [
  { id: 'en_kjv.json', name: 'English - King James Version (KJV)' },
  { id: 'en_bbe.json', name: 'English - Bible in Basic English (BBE)' },
  { id: 'zh_cuv_cantonese.json', name: 'Chinese - CUV, Cantonese' },
  { id: 'zh_cuv_chinese.json', name: 'Chinese - CUV, Chinese' },
  { id: 'es_rvr.json', name: 'Spanish - Reina Valera Revisada (RVR)' },
  { id: 'fr_apee.json', name: 'French - Louis Segond (APEE)' },
  { id: 'ko_ko.json', name: 'Korean - Korean Version' },
  { id: 'he_heb_no_strong.json', name: 'Hebrew - Modern Hebrew Bible' },
  { id: 'he_heb_strong.json', name: 'Hebrew - Modern Hebrew Bible (with Strong\'s)' }
];
```

### 2. State Variables
- `selectedDropdownTranslation`: Current selected translation ID
- `isDarkMode`: Boolean for dark/light mode styling

### 3. Required Functions
- `setSelectedDropdownTranslation()`: Updates the dropdown selection
- `handleApplySelectedTranslationToPane2()`: Applies translation to pane 2

## Button Implementation

### Basic Button Structure
```jsx
<button
  onClick={() => {
    // Cycling logic here
  }}
  className={`ml-2 flex items-center px-2 py-1 text-sm ${isDarkMode ? 'bg-blue-700' : 'bg-blue-500'} text-white rounded hover:bg-blue-600 transition-colors`}
  title="Cycle to next translation and apply to pane 2"
>
  <ChevronRight className="w-3 h-3 mr-1" />
  Next Lang
</button>
```

### Complete onClick Logic
```javascript
onClick={() => {
  try {
    // Find current translation index
    const currentIndex = translations.findIndex(t => t.id === selectedDropdownTranslation);
    
    // Calculate next index (loops back to 0 after last item)
    const nextIndex = (currentIndex + 1) % translations.length;
    const nextTranslation = translations[nextIndex].id;
    
    // Skip Hebrew translations if they cause issues
    let finalTranslation = nextTranslation;
    if (nextTranslation.includes('he_heb')) {
      const afterHebrewIndex = (nextIndex + 1) % translations.length;
      if (translations[afterHebrewIndex] && !translations[afterHebrewIndex].id.includes('he_heb')) {
        finalTranslation = translations[afterHebrewIndex].id;
      }
    }
    
    // Update dropdown selection
    setSelectedDropdownTranslation(finalTranslation);
    
    // Apply translation with delay to prevent scroll errors
    setTimeout(() => {
      try {
        handleApplySelectedTranslationToPane2(finalTranslation);
      } catch (error) {
        console.warn('Error applying translation:', error);
      }
    }, 150);
  } catch (error) {
    console.warn('Error cycling translation:', error);
  }
}}
```

## Error Handling Features

### 1. Try-Catch Blocks
- Wraps the entire function to catch unexpected errors
- Separate try-catch for the application function

### 2. Hebrew Translation Skipping
Some Hebrew translations may cause "BEE text" errors. The code automatically skips these:
```javascript
if (nextTranslation.includes('he_heb')) {
  const afterHebrewIndex = (nextIndex + 1) % translations.length;
  if (translations[afterHebrewIndex] && !translations[afterHebrewIndex].id.includes('he_heb')) {
    finalTranslation = translations[afterHebrewIndex].id;
  }
}
```

### 3. Scroll Error Prevention
A 150ms delay prevents DOM-related scrollTop errors:
```javascript
setTimeout(() => {
  try {
    handleApplySelectedTranslationToPane2(finalTranslation);
  } catch (error) {
    console.warn('Error applying translation:', error);
  }
}, 150);
```

## Common Issues and Solutions

### 1. ScrollTop Errors
**Problem**: "Cannot read properties of null (reading 'scrollTop')"
**Solution**: Add setTimeout delay before applying translation

### 2. Hebrew Translation Errors
**Problem**: "Could not find matching BEE text"
**Solution**: Skip Hebrew translations in the cycling logic

### 3. Styling Inconsistencies
**Problem**: Button doesn't match other UI elements
**Solution**: Use same className pattern as existing buttons (e.g., "Next Ch" button)

### 4. State Not Updating
**Problem**: Dropdown doesn't reflect current selection
**Solution**: Ensure `setSelectedDropdownTranslation()` is called before applying
